# Stunt Bikes — стант-физика для ванильных мотоциклов DayZ

Мод для DayZ 1.30, который превращает ванильные мотоциклы (`Motorbike_01`, `Motorbike_02`) в стант-байки с управлением, близким к настоящему: вилли на газе с точкой баланса, стоппи на переднем тормозе, управление вращением в воздухе и мягкие посадки.

*English summary: realistic wheelies, stoppies and air control for vanilla DayZ 1.30 motorbikes. Scripts only, no new models. Client-authoritative stunt pitch keeps server and client in sync, so there is no rubber-banding during stunts.*

## Управление

| Действие | Клавиша | Что делает |
|---|---|---|
| Газ | W | Поднимает переднее колесо, когда байк уже на заднем; в воздухе поднимает нос |
| Задний тормоз | S | Опускает нос на вилли (спасает от переворота); в воздухе опускает нос |
| Передний тормоз | пробел (ручник) | На скорости поднимает зад — стоппи |
| Наклон назад | ↓ | Нужен, чтобы «подорвать» вилли; в воздухе крутит назад |
| Наклон вперёд | ↑ | Вместе с передним тормозом начинает стоппи; в воздухе крутит вперёд |

Клавиши наклона меняются в настройках управления игры (раздел Stunt Bikes).

## Как это ощущается

- **Вилли.** Потяни руль на себя (↓) и дай газ. Дальше высоту держишь перегазовкой: газ поднимает, гравитация опускает. Около 55° — точка баланса: если перегазуешь и пройдёшь её, байк уйдёт назад, и гонщик упадёт. Задний тормоз опускает нос.
- **Стоппи.** На скорости наклонись вперёд (↑) и зажми передний тормоз. Пережмёшь — полетишь через руль.
- **Воздух.** Вращение сохраняет инерцию. Газ раскручивает заднее колесо и поднимает нос, задний тормоз опускает, наклон телом крутит медленнее.
- **Посадка.** Жёсткое приземление на колёса не сбрасывает гонщика, если байк стоит ровно. Удар в стену и посадка на бок работают как в ванили.

## Установка

1. Скопируй `@StuntBikes` (из релиза или `dist/` после сборки) в папку сервера и клиента.
2. Ключ `@StuntBikes/keys/*.bikey` положи в `keys` сервера.
3. Подключи мод и на сервере, и у игроков: `-mod=@StuntBikes`. Скрипты нужны с обеих сторон.
4. При первом запуске сервер создаст `profiles/StuntBikes/config.json` со значениями по умолчанию.

## Настройки (`config.json`)

Все параметры с комментариями — в [`StuntBikes/scripts/3_Game/StuntBikes/SB_Config.c`](StuntBikes/scripts/3_Game/StuntBikes/SB_Config.c), пример файла — [`config.example.json`](config.example.json). Сервер рассылает настройки игрокам при входе. Самые полезные:

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `ThrottleLiftAccel` | 9 | Насколько сильно газ поднимает перёд |
| `WheelieBalanceAngle` | 55 | Угол точки баланса вилли, ° |
| `GravityPitchAccel` | 7 | Насколько сильно гравитация тянет перёд вниз |
| `RearBrakeDropAccel` | 8 | Насколько сильно задний тормоз опускает нос |
| `FrontBrakeLiftAccel` | 10 | Насколько сильно передний тормоз поднимает зад |
| `ThrottleResponse` | 3 | Плавность газа и тормозов (выше — резче) |
| `AirLeanAccel` / `AirThrottleAccel` / `AirBrakeAccel` | 3.5 / 3 / 4 | Управление вращением в воздухе |
| `LoopOutAngle` / `EndoAngle` | 80 / 80 | Угол, после которого гонщик падает, ° |
| `SafeLandings` | 1 | Мягкие посадки на колёса |
| `ParkObjects` | `[]` | Объекты (рампы и т. п.), которые сервер ставит при старте |
| `DebugLog` | 0 | Подробный лог в `script_*.log` для настройки |

## Как устроено

Ванильный стабилизатор мотоцикла гасит любое вращение по тангажу, поэтому во время станта мод сам ведёт тангаж: считает момент от газа, тормозов, наклона и гравитации и каждый шаг физики (`EOnSimulate`) записывает результат в угловую скорость байка.

Физику станта считает клиент водителя. 20 раз в секунду он отправляет серверу угол и скорость вращения, а сервер ведёт свою копию байка к этому углу с поправкой на задержку. Без этого серверная копия расходилась с клиентской, и сетевая сверка DayZ 1.30 дёргала байк.

| Файл | Назначение |
|---|---|
| `SB_Config.c` | Настройки, загрузка и проверка `config.json` |
| `SB_Control.c` | Стант-физика (вилли, стоппи, воздух) и следование сервера за клиентом |
| `SB_MotorbikeScript.c` | Подключение к `MotorbikeScript`, сетевой обмен, мягкие посадки |
| `SB_PlayerBase.c` | Отправка настроек игрокам, расстановка объектов парка |
| `SB_Missions.c` | Загрузка настроек и парка при старте миссии |

## Сборка

Нужен Python 3. Мод — только скрипты, бинаризация не нужна.

```bat
python tools\build.py
python tools\build.py --sign keys --dsutils "C:\...\DayZ Tools\Bin\DsUtils"
```

Готовый мод появится в `dist\@StuntBikes`. Ключ для подписи один раз создаётся `DSCreateKey.exe` из DayZ Tools и кладётся в `keys\` — эта папка в `.gitignore`, приватный ключ в репозиторий не попадает.

## Локальный тест

`test\run_local_test.bat` собирает и подписывает мод, поднимает отдельный сервер DayZDiag (своё хранилище `instanceId = 77` и свой профиль, основной сервер не затрагивается) и подключает к нему клиент DayZDiag. Серверный мод `test\StuntBikesTest` ставит игрока в поле с двумя готовыми мотоциклами и рампами. Пути в начале батника поправь под себя.

## Ограничения

- Поза гонщика не меняется: в ванили нет анимаций для вилли, видно только движение байка.
- Проверено на DayZ 1.30.164289 (DayZDiag, локальный сервер). На нагруженном сервере с пингом поведение стоит проверить отдельно.
- Положение байка во время станта задаёт клиент (с ограничениями на скорость вращения). Для стант-сервера это нормально, для PvP-сервера учитывай.
