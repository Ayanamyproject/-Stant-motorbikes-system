# Changelog

## 2.0

- Три уровня: Новичок (держишь ↑/↓, байк сам держит угол), Райдер (держишь угол сам, система страхует), Профи (физика MX Bikes).
- Клавиша End меняет уровень, выбор игрока запоминается. Сервер задаёт уровень по умолчанию и может запретить смену.
- Полоска угла на экране с зелёной и красной зонами.
- Газ сам по себе больше не поднимает перёд.
- Физика MX Bikes для уровня Профи: двигатель MSM 250XF, сцепление (правый Shift), виртуальная коробка, вес гонщика, пампинг (правый Ctrl), гироскоп заднего колеса в воздухе, випы и скрабы.
- Байк вращается вокруг пятна контакта колеса, а не вокруг центра масс: больше не «закапывается» задом на вилли.
- Сервер следует за полной ориентацией байка, а не только за тангажом.
- Скорость для трюков берётся из физики тела, а не со спидометра.
- Автотест в серверном тестовом моде.
- Старые `config.json` (версия 5 и ниже) переносятся автоматически: общие настройки сохраняются, физика сбрасывается на новые значения.

## 1.0

- Вилли на газе с точкой баланса, стоппи на переднем тормозе, управление в воздухе, мягкие посадки, синхронизация с сервером.
